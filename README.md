## What Is Full Stack Web Development?

Full stack development means building both sides of a website or web app:

| Part | What It Does | Technologies |
|------|--------------|--------------|
| **Front-end** | What users see and click | HTML, CSS, JavaScript, React |
| **Back-end** | Servers, logic, logins, payments | Node.js, Express.js |
| **Database** | Stores and manages data | MySQL, PostgreSQL, MongoDB |
| **Tools** | Code sharing and going live | Git, GitHub, deployment platforms |

## Who Is This Course For?

## Course Roadmap

**Estimated time: 4 to 9 months (about 2 hours a day)**

### Phase 1: Web Fundamentals (3 to 4 weeks)
- HTML: structure of web pages
- CSS: styling, Flexbox, Grid
- Responsive design for mobile and desktop

### Phase 2: JavaScript (4 to 6 weeks)
- Variables, functions, loops, arrays, and objects
- DOM manipulation and events
- ES6+ features, promises, async/await, and fetch API

### Phase 3: Version Control (1 week)
- Git basics: commit, branch, merge
- Pushing projects to GitHub

### Phase 4: Front-end Framework (4 to 6 weeks)
- React.js components, props, and state
- Hooks and routing
- Connecting the front-end to APIs

### Phase 5: Back-end Development (4 to 6 weeks)
- Node.js and Express.js
- Building REST APIs
- Authentication and security basics

### Phase 6: Databases (3 to 4 weeks)
- SQL basics with MySQL or PostgreSQL
- MongoDB and Mongoose
- Designing simple database structures

### Phase 7: Deployment and Testing (2 weeks)
- Deploying front-end and back-end online
- Environment variables
- Basic testing and debugging

### Phase 8: Capstone Project (3 to 4 weeks)
- Combine everything into one complete full stack app
- Write a clear README for it

## Tips for Students

- Code every day, even for 30 minutes.
- Build projects instead of only watching tutorials.
- Do not skip JavaScript basics.
- Read documentation and learn to debug errors.
- Write a good README for every project.
- Do not wait to feel "ready" before applying.
